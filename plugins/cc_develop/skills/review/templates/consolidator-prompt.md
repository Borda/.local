# Consolidator Agent Prompt — develop:review

Pre-expansion required: before building Agent spawn call, substitute these bare shell variables with resolved literal values:

- $REPORT_DIR_LITERAL — report directory path (resolved in Step 2)
- $DATE — from `date +%Y-%m-%d` output
- $REVIEW_CHECKLIST — resolved checklist path or empty string
- $REVIEW_TEMPLATE — resolved review-report.md template path (Step 5); consolidator reads it itself — never embed the template body in this prompt (double-bills its tokens)

`$RUN_DIR` is the exception — do NOT substitute it. Run-dir preamble (prepended by SKILL.md §Step 5) makes consolidator self-resolve `$RUN_DIR` via `cat "${TMPDIR:-/tmp}/dev-review-run-dir-${CSID}"`; leave `$RUN_DIR` literal in prompt text.

Rank by impact (blocking > critical > high > medium > low). **File head — MANDATORY format:** the file MUST begin with a `---`-delimited YAML metadata block exactly as in the `review-report.md` template — opening `---` on line 1, then the 12 fields in order (`develop-review:`, `Date:`, `Change Type:`, `Scope:`, `Focus:`, `Agents:`, `CI:`, `Outcome:`, `Summary:`, `Confidence:`, `Next steps:`, `Path:`), then closing `---`, then body.
